# Das Blasse Haus

Ein Horrorspiel im Browser (1.0 Beta).

**Jetzt spielen:** https://levithomas15.github.io/Das-blasse-Haus-Horror-Spiel-1.0-Beta-/

Finde die fünf Tagebuchseiten. Finde die Tür. Und dreh dich nicht um.

⚠ Sehr laute Jumpscares und flackerndes Licht.

## Monster

- **Die Blasse** jagt dich, sobald du die erste Seite hast.
- **Der Demogorgon** taucht auf, nachdem du zwei Seiten gefunden hast. Hör auf das Stampfen und Knurren. Wenn er dich sieht, öffnet sich sein Kopf und er brüllt. Renn!
- **Kriecher** und **Hohler** lauern bei den Hände-Events.

## Steuerung

- **PC:** WASD oder Pfeiltasten laufen, Maus umsehen, Shift rennen, F Taschenlampe, Esc Pause
- **Handy:** linker Daumen laufen, rechter Daumen umsehen, „Licht“-Knopf für die Taschenlampe
